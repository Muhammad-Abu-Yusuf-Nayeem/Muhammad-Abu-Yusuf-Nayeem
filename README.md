*From messy operational data to structured, analysis-ready information*

A large-scale data preparation project focused on cleaning and restructuring land/property-related data.

The project explores how raw operational datasets can contain:

- Inconsistent names
- Duplicate records
- Different naming formats
- Missing values
- Inconsistent data types
- Invalid values
- Structural inconsistencies
- Multiple representations of the same entity

**Data Quality Approach**

Instead of simply deleting problematic records, each issue is classified based on whether the information can be recovered.

```text

     ↓
```

## My Approach to Data Problems

I generally approach a data problem through five stages:

**01 — Understand**
What is the actual business problem?

**02 — Profile**
What does the data look like? What is missing, inconsistent, duplicated, or unreliable?

**03 — Transform**
Clean, standardize, restructure, and validate the data.

**04 — Analyze**
Find patterns, KPIs, exceptions, trends, and actionable insights.

**05 — Automate**
If the same process will happen again, automate it.

> The goal is not only to produce one good report.
> The goal is to build a process that can reliably produce the next report.
