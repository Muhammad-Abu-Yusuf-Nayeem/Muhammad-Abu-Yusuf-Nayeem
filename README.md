# 💡 How I Think About Data

A dashboard is only the **visible part** of a data solution.

I focus on the complete system:

| Stage         | Question                            |
| ------------- | ----------------------------------- |
| 🎯 Understand | What problem are we solving?        |
| 🔍 Profile    | Can we trust the data?              |
| 🧹 Transform  | How should the data be cleaned?     |
| 📊 Analyze    | What does the data tell us?         |
| ⚡ Automate    | Can the process be made repeatable? |

> **Good analysis answers today's question.
> Good systems make tomorrow's analysis easier.**
